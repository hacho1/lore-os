# LoreOS

소설이나 게임의 **세계관 위키, 캐릭터 관계도, AI 초안 검토**를 한 작업 공간에 모은 한국어 창작 도구입니다. 원본 설정을 보관하고, AI가 제안한 변경은 작성자가 내용을 확인하고 승인한 뒤 반영합니다.

## 주요 기능

- **세계관 위키** — 캐릭터·조직·장소·아이템·사건을 마크다운으로 정리하고 태그, 참조, 버전 이력을 관리합니다.
- **캐릭터 관계도** — 노드를 옮기고 관계를 탐색·편집합니다. 캐릭터 소속과 관계선의 변경을 함께 저장합니다.
- **원본 보관과 파생 캐릭터** — 전역 원본과 세계관별 파생 버전을 분리해 저장하고, 이름이나 능력 등 보호할 필드를 지정합니다.
- **AI 제안 검토** — 자료 속 후보를 찾거나 선택한 문단의 수정을 제안합니다. 변경 전후와 근거·충돌 경고를 확인하고 승인·거절할 수 있습니다.

## 기술 스택

| 영역 | 사용 기술 |
| --- | --- |
| 웹 | Next.js App Router · React · TypeScript · React Flow |
| 데이터 | SQLite · Node.js 내장 `node:sqlite` · Zod |
| AI·검증 | OpenAI Responses API · JSON Schema 구조화 출력 · Playwright · Node.js 테스트 러너 |

## 실행 방법

**Node.js 24 이상**을 설치한 뒤 저장소 루트에서 실행합니다.

```bash
npm ci --cache ../loreos-npm-cache
npm run dev
```

[127.0.0.1:3000](http://127.0.0.1:3000)에서 예시 세계관 **달이 잠든 바다**를 열어 볼 수 있습니다. 기본 데모 모드에서는 API 키가 필요 없으며, 빈 DB에는 처음 접속할 때 예시 데이터가 들어갑니다. `--cache` 옵션은 저장소에 기록된 개발 환경의 D: 캐시 경로 대신 로컬 폴더를 사용합니다.

실제 AI를 연결하려면 [환경변수 예시](.env.example)를 `.env.local`로 복사하고 `LOREOS_AI_MODE=openai`, `OPENAI_API_KEY`, 사용할 `OPENAI_MODEL`을 지정합니다. 실제 모드에서는 작업에 선택한 자료와 설정이 OpenAI로 전송됩니다.

## 사용 흐름과 검증

1. 원본 보관함에서 캐릭터를 등록하고 AI가 바꿀 수 없는 필드를 선택합니다.
2. **세계관에 적용**으로 파생 제안을 만들고, 변경 내용을 검토한 뒤 승인합니다.
3. 관계도에서 파생 캐릭터의 연결을 확인하거나 원하는 문단을 골라 수정 제안을 요청합니다.

`npm test`로 핵심 로직을, `npm run typecheck`로 타입을 확인합니다. 기본 앱은 127.0.0.1에 바인딩하는 개인용 MVP입니다. 별도 웹 구성은 [sites/loreos-web](sites/loreos-web/README.md)에 있습니다.

데이터베이스 초기화, OpenAI 설정과 E2E 실행 예시는 [기존 개발 README](https://github.com/hacho1/lore-os/blob/9d335c40dfe69e74c721b1503dac61e022c3cd07/README.md)에 기록되어 있습니다.
