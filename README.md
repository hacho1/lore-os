# LoreOS

세계관 위키, 캐릭터 관계도, 검토 가능한 AI 창작·수정 도우미를 연결한 **로컬 단일 사용자용 MVP**입니다. 모든 UI·오류 안내·예시 설정은 한국어입니다.

## D드라이브에서 실행

작업 폴더는 **D:\LoreOS**입니다. Node와 npm도 프로젝트 내부에 들어 있습니다. C드라이브에 설치된 Node에 의존하지 않으려면 아래 실행 파일을 사용하세요.

```powershell
cd D:\LoreOS
.\loreos.cmd
```

[http://127.0.0.1:3000](http://127.0.0.1:3000)을 열면 됩니다. 종료는 실행 창에서 Ctrl+C입니다. 기본 런처는 빌드된 실행본이 있으면 그것을 실행하고, 없을 때는 개발 서버를 엽니다. 코드를 수정할 때는 `run dev`를 사용하세요.

```powershell
# 이미 설치되어 있으므로 보통 다시 설치할 필요가 없습니다.
.\loreos.cmd ci

# 개발 실행
.\loreos.cmd run dev

# 타입·핵심 로직·실제 브라우저 테스트
.\loreos.cmd run typecheck
.\loreos.cmd test
.\loreos.cmd run test:e2e

# 프로덕션 빌드와 실행
.\loreos.cmd run build
.\loreos.cmd start

# DB 초기화: 기존 자료를 지우지 않습니다.
.\loreos.cmd run db:init
```

PowerShell에서 직접 개발하려면 먼저 `. .\scripts\use-local-runtime.ps1`를 실행하세요. 이후 `node`, `npm`은 프로젝트 내부 런타임을 우선 사용합니다. D드라이브가 파일 소유권을 기록하지 않는 환경에서도 이 세션의 Git은 `D:/LoreOS` 저장소를 사용할 수 있게 설정됩니다. C드라이브의 전역 Git 설정은 바꾸지 않습니다.

| 항목 | 저장 위치 |
| --- | --- |
| 소스·설정 | D:\LoreOS\src, 프로젝트 루트 |
| 설치한 패키지 | D:\LoreOS\node_modules |
| Node·npm | D:\LoreOS\.runtime\node |
| npm 다운로드 캐시·로그 | D:\LoreOS\.runtime\npm-cache |
| 전역 npm 설치 경로 | D:\LoreOS\.runtime\npm-global |
| 임시 파일·브라우저 임시 프로필 | D:\LoreOS\.runtime\temp |
| 테스트용 Chromium | D:\LoreOS\.runtime\browsers |
| SQLite 데이터 | D:\LoreOS\data\loreos.sqlite |
| 개발·빌드 캐시 | D:\LoreOS\.next |
| 테스트 빌드·DB | D:\LoreOS\.next-e2e, data\e2e-*.sqlite |
| 테스트 결과 | D:\LoreOS\test-results, playwright-report |

런처가 PATH, TEMP, TMP, npm 캐시, Playwright 브라우저 경로를 이 폴더들로 설정합니다. Codex 앱, 운영체제, 사용자의 기존 브라우저와 공용 개발 도구는 이동하지 않습니다. 처음 의존성을 설치할 때 기존 공용 npm 캐시가 사용되었지만, 이후 작업은 D드라이브 캐시를 사용합니다. 공용 캐시는 다른 프로젝트의 자료가 섞여 있어 삭제하지 않았습니다.

## 첫 실행과 핵심 사용 흐름

1. ‘달이 잠든 바다’라는 독자적인 예시 세계관이 열립니다. 예시 표시가 있으며 사용자 프로젝트와 분리됩니다.
2. 왼쪽 프로젝트 전환 옆 **+**로 새 세계관을 만듭니다.
3. **참고 자료 → 자료 추가**에서 원본 텍스트를 붙여 넣습니다.
4. **원본 보관함 → 원본 등록**에서 자캐를 등록하고 이름·능력 등의 **AI 수정 금지**를 선택합니다.
5. 원본 문서의 **세계관에 적용**을 눌러 파생 버전 제안을 요청합니다.
6. 변경 전후, 변경 이유, 근거와 충돌 경고를 읽고 **승인하고 공식 설정에 반영**합니다.
7. 파생 버전에서 **AI와 이어 쓰기**를 열고 수정 범위를 선택합니다. 예: 소속만 선택하고 “성격은 그대로 두고 소속만 황혼회로 바꿔 줘.”
8. 다시 승인하면 문서와 소속 관계가 한 트랜잭션으로 반영됩니다. 원본은 변경되지 않습니다.

소속으로 사용할 조직은 먼저 등록하세요. 관계도는 노드 이동·확대/축소·전체 보기·유형 필터를 지원합니다. 노드 선택은 상세 패널, 두 번 클릭은 문서, 연결선 클릭은 관계 편집입니다. 이동한 위치도 저장합니다.

본문은 마크다운입니다. 미리보기, 목차, 직접 연결·역참조, 버전별 기록을 제공합니다. AI 패널에서 본문을 선택하고 **정확한 변경값·문단 지정**을 열면 특정 원문 문단만 수정할 수 있습니다. 같은 문단이 여러 번 있으면 첫 일치 구간을 사용합니다.

## 데이터베이스 선택과 초기화

Node 24의 내장 `node:sqlite`와 SQLite를 사용합니다. 현재 Windows 환경에서 별도의 DB 서버·Docker·네이티브 모듈 빌드 없이 실행할 수 있어 선택했습니다. Prisma는 추가하지 않았습니다.

- 앱의 첫 API 요청 또는 `db:init`이 테이블과 스키마 버전 1을 생성합니다.
- DB에 프로젝트가 전혀 없을 때만 예시 데이터를 추가합니다.
- 초기화는 기존 사용자 자료를 덮어쓰지 않습니다.
- 기본 저장 파일은 `data/loreos.sqlite`이며 WAL 모드를 사용합니다.
- 백업은 서버 종료 후 SQLite 파일을 복사하는 방식이 가장 단순합니다. 실행 중에는 -wal/-shm 파일도 존재할 수 있으므로 본체만 임의 복사하지 마세요.
- 설정의 JSON 내보내기는 현재 세계관과 원본의 열람·보관용입니다. JSON 가져오기는 미구현입니다.
- 테스트는 별도 DB를 생성하므로 실제 작업 DB를 사용하지 않습니다.

자세한 모델과 승인 규칙은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)에 있습니다.

## 실제 AI 연결

기본 실행은 **데모 모드**이며 API 키가 필요하지 않습니다.

```powershell
Copy-Item .env.example .env.local
```

`.env.local`을 직접 편집합니다.

```dotenv
LOREOS_AI_MODE=openai
OPENAI_API_KEY=발급받은_키
OPENAI_MODEL=gpt-4.1-mini
LOREOS_DB_PATH=./data/loreos.sqlite
```

서버를 재시작하세요. API 키는 서버에서만 읽으며 브라우저에 전달하지 않습니다. 키 파일은 gitignore에 포함됩니다. 모델은 계정에서 사용할 수 있는 Structured Outputs 지원 모델로 변경할 수 있습니다. 실제 모드에서는 선택한 자료·현재 설정이 OpenAI로 전송됩니다.

OpenAI SDK의 Responses API와 엄격한 JSON Schema를 사용하고, 수신 결과를 Zod로 다시 검증합니다. 작업당 API 호출 1회, 자동 재시도 0회, 요청 제한 시간 35초, 출력 최대 6,500토큰, 프로젝트당 동시 작업 1개·분당 8회입니다. 모델 입력에는 최대 24개 엔티티 요약과 선택 자료 최대 8개를 넣으며 본문 길이를 제한합니다. 전체 지식베이스 검색이나 벡터 RAG는 아닙니다.

API 인증 실패·한도 초과·빈 응답·스키마 불일치는 오류로 표시합니다. **실제 실패를 데모로 대체하지 않습니다.** AI에는 공식 설정을 저장하는 도구가 제공되지 않습니다.

참고한 공식 문서: [OpenAI 구조화된 출력](https://developers.openai.com/api/docs/guides/structured-outputs), [Next.js App Router](https://nextjs.org/docs/app/getting-started/installation), [React Flow](https://reactflow.dev/learn), [Node SQLite](https://nodejs.org/api/sqlite.html).

## 구현된 기능

- 프로젝트 생성·전환, 실제 데이터 기반 개요, 최근 수정, 검토 대기 목록
- 캐릭터·조직·장소·아이템·사건·세계관 문서 생성 및 편집
- 마크다운 미리보기, 태그, 이미지 주소, 필드별 보호, 변경 이력
- 전역 원본 캐릭터와 프로젝트별 파생 버전의 별도 저장·계보 추적
- 방향·이름을 표시하는 관계도, 드래그 위치 저장, 유형 필터, 관계 추가·수정·삭제
- 소속 필드와 ‘소속이다’ 관계의 양방향 동기화
- 텍스트 자료 원본 저장, 출처 URL·권리 정보 기록
- 자료에서 추출한 후보·추론·창작의 구분과 원문 인용 검증
- AI 생성·부분 수정·파생 버전·자료 후보 추출, 검토·승인·거절·재수정
- 승인 단계의 보호 필드·버전·프로젝트 범위 재검증
- 문서·관계·이력·제안 상태의 SQLite 트랜잭션 처리
- 프로젝트 내 검색, 원본 검색, 좁은 화면의 패널 서랍
- 로컬 데이터 JSON 내보내기

## 데모 처리와 제한

- 데모 생성은 정해진 예문과 규칙을 조합합니다. 자유로운 자연어 이해를 하는 실제 모델이 아닙니다.
- 데모 수정은 선택 범위, 등록 조직 이름, 직접 지정한 변경값을 이용합니다.
- 데모 자료 추출은 `인물: 이름 — 설명` 등으로 시작하는 첫 해당 줄을 후보 하나로 만듭니다. 분석 유형은 AI 지시에서 선택할 수 있습니다.
- 능력·규칙·관계 추출 결과는 문서 후보입니다. 관계선으로 자동 정규화하지 않으며 승인 후 직접 연결합니다.
- 자동 충돌 확인은 보호 필드·참조·일부 명시적 금지 규칙 검사입니다. 모든 의미상 충돌을 판단하지 않습니다.
- 원문이 제안 후 바뀌면 덮어쓰기를 거절합니다. 프로젝트의 다른 문서·관계·자료 변경도 안전하게 오래된 제안으로 처리하므로 재생성이 필요할 수 있습니다.
- 관계 추가·소속 편집은 사용자 직접 편집입니다. AI 보호는 AI 경로에 적용되며 사용자 직접 편집을 막지 않습니다.
- 엔티티·프로젝트 삭제, 자료 편집, 휴지통, 되돌리기, 고급 연대표, 실시간 협업, 인증은 미구현입니다.
- URL은 출처로만 저장합니다. 자동 수집·로그인 우회·서버 URL 요청은 하지 않습니다.
- 이미지 업로드·이미지 생성은 없고 이미지 주소를 지원합니다. 첨부 참고 이미지의 로고·캐릭터·문구는 사용하지 않았습니다. 예시 표식과 풍경은 프로젝트 고유 SVG입니다.
- 한국어 폰트는 로컬 번들입니다. 최초 컴파일은 폰트 처리와 D드라이브 속도에 따라 몇 분 걸릴 수 있습니다.
- **인증이 없는 개인용 로컬 MVP입니다. 공개 배포용 서비스가 아닙니다.** 기본 서버는 127.0.0.1에만 바인딩합니다.

## 검증

실행한 결과는 [docs/VERIFICATION.md](docs/VERIFICATION.md)에 기록합니다. 실제 API 키를 이용한 유료 모델 호출은 검증하지 않았습니다. API 키 누락 시 실패 처리와 데모 대체 방지는 자동 테스트합니다.

D드라이브에서 개발 서버의 첫 컴파일이 오래 걸리면 이미 빌드된 실행본으로 E2E를 검증할 수 있습니다.

```powershell
. .\scripts\use-local-runtime.ps1
npm run build
$env:LOREOS_E2E_PRODUCTION = '1'
npm run test:e2e
```

디자인 기준은 [docs/DESIGN.md](docs/DESIGN.md)입니다.
